# Eastsek AB hemsida

Statisk hemsida redo för GitHub Pages.

## Så publicerar du på GitHub Pages
1. Skapa ett nytt repository på GitHub, t.ex. `eastsek-ab`.
2. Ladda upp alla filer i denna mapp.
3. Gå till Settings → Pages.
4. Under "Build and deployment", välj Deploy from a branch.
5. Välj branch `main` och folder `/root`.
6. Sidan publiceras på en adress i stil med `https://anvandarnamn.github.io/eastsek-ab/`.

## Saker att ändra innan publicering
- Byt e-post i `index.html` och `script.js` från `info@eastsek.se` om annan e-post ska användas.
- Lägg in rätt telefonnummer och bolagsadress.
- Vill ni ha riktigt formulär direkt från sidan kan Netlify Forms eller Formspree kopplas in.
